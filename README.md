# SQL Portfolio

This repository contains SQL projects demonstrating my ability to create, query, combine, filter, and analyze relational data to answer business questions.

## Project 1: Film Rental Business Analysis

This project analyzes a film rental database to answer questions related to sales, customers, films, locations, and staff performance.

### SQL Skills Demonstrated
- SELECT and DISTINCT
- WHERE and filtering
- CASE statements
- COUNT, SUM, and AVG
- GROUP BY
- INNER JOIN and LEFT JOIN
- Multiple-table joins
- Subqueries
- ORDER BY
- Aliases and string concatenation

### Business Questions
- Which film categories contain the most titles?
- Which actors appear in the most films?
- Which cities generate the most sales?
- How does revenue vary by country and city?
- What is the average revenue generated by each staff member per customer?

➡️ **Project file:** `film_rental_business_analysis.sql`

### SQL Skills Demonstrated

### Business Questions

- How many training hours has each department completed?
