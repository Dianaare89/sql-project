# SQL Film Rental Database Analysis

## Project Overview
This project demonstrates my SQL skills by analyzing a film rental database to answer business questions related to films, customers, sales, locations, and staff performance.

The project progresses from basic queries to more complex analysis using multiple tables and subqueries.

## SQL Skills Demonstrated
- SELECT and DISTINCT
- WHERE and filtering
- ORDER BY
- CASE statements
- Aggregate functions: COUNT, SUM, AVG
- GROUP BY
- INNER JOIN and LEFT JOIN
- Multiple-table joins
- Subqueries
- Aliases
- String concatenation

## Business Questions Analyzed
Examples of questions answered in this project include:

- Which film categories contain the most titles?
- Which actors appear in the most films?
- Which addresses are not associated with customers?
- Which cities generate the most sales?
- How does revenue differ across countries and cities?
- What is the average revenue generated by each staff member per customer?
- How can films be grouped into different replacement-cost ranges?

## Example Query

The following query calculates average revenue per customer for each staff member:

```sql
SELECT
    staff_id,
    ROUND(AVG(total), 2) AS avg_amount
FROM (
    SELECT
        SUM(amount) AS total,
        customer_id,
        staff_id
    FROM payment
    GROUP BY customer_id, staff_id
) a
GROUP BY staff_id;
